# Лист — сайт городского кафе (учебный проект)

Сайт: https://knifell.github.io/list-cafe/

Меню с поиском и фильтрами, избранное, корзина и заказ через WhatsApp (в демо получатель не задан, заказ не отправляется автоматически). Бронирование столика готовит текст заявки.

- Меню, контакты и условия — `config.js`
- Внешний вид — `styles.css`
- Логика — `app.js`
- Источники фото — `SOURCES.md`, лицензия шрифта — `assets/FONT-LICENSE.txt`

Статический сайт: HTML, CSS, JavaScript. Сборка не нужна. Публикуется через GitHub Pages из ветки main.
